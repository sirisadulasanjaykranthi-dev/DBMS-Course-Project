How to update MySQL Password

Your MySQL credentials can be adjusted in the .env file in the project folder:

# .env file
MYSQL_HOST=localhost
MYSQL_PORT=3306
MYSQL_USER=root
MYSQL_PASSWORD=your_actual_mysql_root_password
MYSQL_DATABASE=solar_service_db

Alternatively, you can edit database.py directly.
